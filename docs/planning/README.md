# Planning documents

These were written on the day of the Build for Ireland hackathon (4 October
2026), before and during the build. They are kept as a record of how the
project was scoped and are not a description of the finished prototype.

- [PLAN.md](PLAN.md): the original idea and milestones.
- [SPEC.md](SPEC.md): the MVP spec and two-person work split.
- [IMPLEMENTATION_GUIDE.md](IMPLEMENTATION_GUIDE.md): build order, data model,
  and the reasoning behind the "not observed is not cancelled" rule.

Several planned features (trip planning, fares, Dublin Bikes, a reliability
dashboard) were not built in the time available. See the main
[README](../../README.md) for what the prototype does.
